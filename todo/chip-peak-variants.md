# 筹码峰算法改版：双分布（Y 轴负值）+ 两条衰减路线

> 2026-10-15 方向确认。本轮**只定方案，不写实现**。
> 历史文档（两变种 tri_decay vs ema_decay）的决策保留在附录 A。

---

## 0. 本轮方向

把筹码峰从**单分布**改成**双分布镜像**：

- 以某个成交量为 base（记 **B**），过滤掉"自然换手"；
- 低于 B 的日子 → 累积为**固定筹码**（锁仓穿越）；
- 高于 B 的日子 → 累积为**强换手**；
- 两份分布画在同一张图上，**数值轴一侧为负**。

**不变的**：日线 + 三角分布摊布（M0 不动）。

**待选的**：衰减律仍走两条 —— ① 沿用 K 衰减系数；② 参考 EMA 时间权重。

---

## 1. B 的定义

> "完成 100% 换手的时间，计算这个时间的平均换手。"

```
N_mean = 完成 100% 换手所需的天数（= 累计换手率回溯到 100% 的天数，见 §6）
B      = float_cap / N_mean
       ≡ N_mean 天窗口内的日均成交量
```

即：**B 就是"自然换手一天"的成交量基准**。`VOL[t]` 与 B 比大小，即为"换手强度"。

### 1.1 B 逐日滚动（2026-10-15 拍板）

**决策：`B[t]` 逐日计算，不做全样本一次算定。**

理由（认可）：逐日识别解禁/增发是**必做动作**，与 B 怎么定无关；既然股本序列要逐日算，
B 顺水推舟逐日算即可 —— 实际考虑因素更少，更能落地。且天然满足"截至 t"、无前视偏差。

```
N_smooth[t] = EMA(span=20) of N[t]        # 沿用原 M1 口径，本身就是逐日的
B[t]        = float_cap[t] / N_smooth[t]
```

**配套补强（重要）：区分两种"B 的变化"，只允许前者。**

| B 变化来源 | 是否要 | 说明 |
|---|---|---|
| `float_cap[t]` 变化（解禁/增发） | **要** ✅ | 真实的基本面变化：同样的成交量摊在更大股本上，换手强度理应下降 |
| `N_smooth[t]` 的估计噪声 | **要压掉** ⚠️ | 口径性漂移 → 历史分类标准前后不可比，回溯曲线失真 |

→ **`N_smooth` 必须用长窗口平滑估计**（原口径 `N[t]` + `EMA(span=20)` 已是平滑逐日量，符合此要求）。
不要改用瞬时 `N[t]` 或短窗统计，否则 B 门槛会随行情噪声跳动。

**除权日的正确性检查**：价格用 qfq、股本用**不复权原值**、成交量用原始手数 —— 三者口径天然一致，
`turnover[t] = VOL[t]×100 / float_cap[t]` 正确。不要对股本做复权。

**数据层需求**：逐日 `float_cap[t]` 需要 `float_shares_series(code, start, end)`
（一次 SQL 取回 + 前向填充，**不要** 250 次单查）。`float_shares_at(code, date)` 已有单点查询，
`share_capital` 表也已支持历史 `as_of`（`price_store.py:684`），只差 Tushare 补历史节点。

**降级**：无历史股本时 `float_cap[t]` 用当前值 → 除权日前后失真。输出列 `float_share_source`
标注 `tushare_float_share` / `current_approx`。

**输出列必须带** `N_mean` 与 `B`（逐日），判定离线做、便于事后换阈值重算。

### 1.2 分类规则：**基线 = 三分类（`<B` / `[B,2B)` / `≥2B`）**

用户表述只覆盖两侧，中间区间未定义。**推荐先做三分类作基线**，实现后横向对比（§1.4）。

| 方案 | 规则 | 量级估算（自然换手日 VOL 右偏，几何分布均值 B） |
|---|---|---|
| 二分类 | `VOL < B` → 固定；`VOL ≥ B` → 强换手 | D_fix 累积约 **42%** 成交量，D_hot 累积约 **58%** → 强换手侧把大量"正常换手日"也吃进去，**两侧严重不平衡**、标签失真 |
| **三分类（基线）** | `VOL < B` → 固定；`B ≤ VOL < 2B` → 自然换手（**不计入任一分布**）；`VOL ≥ 2B` → 强换手 | D_fix 约 **42%**、D_hot 约 **25%** → 两侧都不稀疏、量级对称 ✅ |

选三分类的核心理由：**中间区间被显式挖掉本身就是信息** —— 它量化了"既不算固定也不算强换手"的正常换手占比。
二分类把这个信息丢掉了。

### 1.3 判别量：**基线 = 瞬时 `VOL[t]`**

单日 `VOL` 噪声极大（涨停日、公告日、题材日动辄 5~10 倍常态），这是三分类的主要风险点。
但**基线就用瞬时值**，理由：最小实现、先把管线跑通，噪声问题放到 §1.4 横向对比里定量看。

- **不可行的写法**：拿 `MA_N(VOL)` 与 B 比 —— B 本身就是 N 日均量，`MA_N < B` 恒成立（自指，恒为假）。❌

### 1.4 横向对比矩阵（实现后跑，按实测结果定参数）

基线跑通后，同一份数据只换「判别量 × 阈值」两个维度做对比：

| 维度 | 候选 |
|---|---|
| **判别量** | 瞬时 `VOL[t]`（基线） / `MA_5` / `MA_10` / 滚动分位数（`VOL[t]` 在过去 W 日的分位） |
| **强换手阈值** | `2B`（基线） / `1.5B` / `3B` |
| 锁仓阈值 | `B`（固定，即"自然换手基准"，不动） |

观察指标（决定选哪个）：两侧分布的**成交量占比**（是否失衡）、`D_fix` 的**峰位稳定性**
（跨日抖动小才说明分类稳）、以及两侧峰位**分叉的时点**是否对应大阳线/公告日。

## 2. 双分布的构造：残差法（唯一能保证非负的做法）

设衰减器为同一个递推 `chips *= decay_factor_t; chips += inject_t`（衰减律 ①② 皆可套用）。

```
D_all  = 注入【全部】日子的递推结果                    # = 现有单分布
D_hot  = 只注入【VOL[t] ≥ B】的日子的递推结果          # 强换手分布
D_fix  = D_all − D_hot  ≡  只注入【VOL[t] < B】的日子的递推结果   # 固定筹码分布
```

**为什么必须是残差法**：

| 做法 | `D_fix ≥ 0` 是否保证 |
|---|---|
| **残差法**（D_all − D_hot，衰减器完全相同） | **恒成立** —— 因为 D_all 恰好就是"全部日子注入"，减去强换手日后剩下的必然非负 ✅ |
| 并行法（分别算 D_hot 和 D_low 再相减） | **不保证** —— 两侧各自衰减，衰减因子不同，相减可出负数 ❌ |
| 直接跑一个"只注入缩量日"的新公式 | 等价于残差法，可行；但必须与 D_all **共用同一个衰减器实例口径**，否则口径漂移 |

**结论：残差法与衰减律正交。** 先用任一衰减律把双分布跑通，再比衰减律 —— 不要同时改两件事。

### 2.0 表示形式：**两条独立非负序列**（2026-10-15 拍板，推荐）

坐标系已定为**数值轴（宽度）给负**，但这**不等于**要在数据层用负号表示。

**推荐：后端仍输出两条独立的非负序列**（`pct_hot` / `pct_fix`，各自非负、各自归一化口径明确），
**符号（左右分侧）完全由渲染层加**。

理由 —— 这一步把 §5 的四个"必须改"直接清零：

| 契约检查 | 单矩阵带符号 | 两条独立非负序列 |
|---|---|---|
| `_as_matrix` 非负校验（`base.py:126-127`） | ❌ 要改 | ✅ **不用改** |
| registry 冒烟（`registry.py:137-147`） | ❌ 要改 | ✅ **不用改** |
| `_normalize_rows` 行和 ≤0 失效（`base.py:131-138`） | ❌ 要改 | ✅ **不用改** |
| 现有指标侧（`chip_profit`/`chip_cost`/`chip_scr`） | ⚠️ 波及 | ✅ **零影响**（默认仍返回单分布） |

→ 改动面收缩为：**新增公式参数/响应字段 + C# 渲染左右分绘**，现有单分布链路完全不动。

**两条铁律**（否则数值会错）：

1. **减法必须在原始（未归一化）尺度上做** —— `D_fix = D_all − D_hot` 用同一衰减器的原始输出相减。
   绝不能先各自归一化到 100 再相减（两者行和差 4 倍，相减必出负数）。
2. **归一化只在最后一步**，且两侧共用同一分母：

```
base = D_all[-1].sum()                       # 同一分母 = 全部筹码
pct_all[t] = D_all[t] / base      * 100      # 现有单分布，口径不变
pct_hot[t] = D_hot[t] / base      * 100      # 强换手
pct_fix[t] = D_fix[t] / base      * 100      # 固定筹码
```

→ 图上两侧之和 = 100% − 中性区间占比（约 **75%**），**留白就是"自然换手"的份额**。
这是有意的：X 轴刻度标到 100，留白直接可视化为正常换手的体量。若两侧各自归一化到 100 会丢掉这个相对量信息。

### 2.0.1 渲染侧的符号与几何（坐标系已定：数值轴/宽度给负）

| 侧 | 内容 | 宽度 |
|---|---|---|
| 左 | 固定筹码 `pct_fix` | **负** |
| 中轴 | x = 0 | 0 |
| 右 | 强换手 `pct_hot` | **正** |

- 纵轴 = 价格轴，**完全不变**，与 K 线继续共享几何；
- 值域改为**取两侧绝对值的最大者**：`maxPct = max(|pct_hot|, |pct_fix|)`，不能像现在一样从 0 起只取正侧；
- 两侧多边形的闭合基准边都是**中轴**（不是现在的左轴 `LeftPad`）；
- 满刻度标签要对称标注（如 `±X%`）。

### 2.1 与旧 `net_lockup` 的口径区别（必须澄清）

| 名称 | 定义 | 类型 |
|---|---|---|
| 旧 P1-1 `net_lockup` | 锁仓日**占比** − 强换手日**占比**（窗口 N_mean 内） | **时序**占比差 |
| 本轮双分布 | `D_fix`（价格分布之差） | **横截面**分布差 |

两者不是同一个量，不能互相替代。旧定义可作为双分布的**辅助标量**（`net_lockup_ratio`）一并输出。

## 3. 衰减路线（两条，待选/待定）

双分布结构（§2）与衰减律正交 → 两种衰减律 × 双分布 = 4 种组合。建议先固定一条衰减律把双分布跑通。

### 3.1 路线 ① —— 沿用 K 衰减系数 ✅ 已定：注入 `k`（= 现有实现）

现有 `tri_decay` 的 `decay`（公式参数，扫描区间 1.0~2.0）。

**2026-10-15 拍板：注入 `k`（现有实现），不是原规格的 `VOL[t]`。**
即 `chips += k · tri_t`，`k = min(1, turnover[t] · decay · lockup)`，`sum(chips) ≡ 1`。

理由：总量恒为 1 → 自动免疫 VOL 单位问题；与线上 SCR90 榜同源；`decay` 语义清晰（单日筹码更新率）；
不改动 `tri_decay` 现有数值口径 → 零回归风险。

**本轮范围外**（记下备查）：是否带 `lockup_factor` 修正 —— 线上带，故后续对比实验须两版口径一致。

### 3.2 路线 ② —— EMA 时间权重 ✅ 已定：候选 A（`period = N_mean`）

```
α = 2/(period+1),  λ = 1−α
y[t] = α·x[t] + λ·y[t−1]                     # 递推式，天然逐日，O(T×bins)
```

**2026-10-15 拍板：候选 A —— `period = N_mean`，语义 =「用满 N 个交易日的信息」。**

依据：`N_eff = (1+λ)/(1−λ) = (2−α)/α`，代入 `α = 2/(period+1)` 得
**`N_eff = period`（精确恒等式）** → `period = N` 即"等效样本数恰为 N"，口径最干净、无隐含系数。

| 量 | `period = N_mean` |
|---|---|
| 等效样本数 | `= N_mean` |
| 半衰期 | `≈ 0.347 · N_mean`（**不是** N，也不是 N/2） |
| 达 95% 稳态 | `≈ 1.5 · N_mean` |
| 达 99% 稳态 | `≈ 2.3 · N_mean` |

> 口径说明：本路线的"完成 100% 换手"定义为**等效样本数 = N**（而非"权重降到某个固定比例"），
> 因此半衰期是 `0.347N` 而不是 N —— 若后续发现半衰期偏短，改 `period = f(N)` 的 f 即可，不必改公式。

**其他已消解**：`N` 取**全样本均值**（逐日会让 λ 变化 → 重新引回"直接求和 ≠ 递推"的 1.5% 差异）；
λ 恒定 → 递推 ≡ 直接求和；递推天然产出逐日分布。

### 3.3 路线② 的硬约束（原规格完全没写）

设可用 bars 长度 T、输出窗口 W：

- 稳态：`1.5·period ≤ T`（95%）/ `2.3·period ≤ T`（99%）
- 样本充足：`period ≤ W`

现有 `WARMUP_RATIO = 1.0`（预热 = 1 倍窗口）**远不够**：`period = 3N` 时预热要 `≈ 4.5N ~ 6.9N` 天。

**推论**：`N > T/7` 的票，现有 bars 长度下**路线② 不可用**。低换手大盘股会成批命中，必须有降级策略（回溯更长历史 / 用全样本 N / 标记不可用）。

→ **动手前第一步：统计 N 分布（300 只，看 p50/p90/max + `N > T/7` 占比）。** 这一个数字决定 `period = f(N)` 能否落地、以及实验样本怎么抽。

## 6. 换手周期 N 的计算口径（不动三角分布，但这条要改）

原 M1 规格收 `vol`（单位"手"）+ `float_cap`（单位"股"）→ **单位陷阱**。
已确认上游 `get_turnover`（`indicators/data.py:132-137`）**已经**做完 `volume(手)×100 ÷ float_shares(股)` 并返回无量纲小数。

→ **改为直接吃 turnover，彻底绕开单位问题**（顺带消解原 P2-1 / P2-2）：

```
cum    = turnover.cumsum()                     # 累计换手率，无量纲
target = searchsorted(cum, cum − 1.0)          # 回溯到累计换手 100%   O(T)
N      = target − arange(T) + 1
N[cum < 1.0] = np.nan                          # 初始无效段剔除
```

- ⚠️ **短窗口可能全 NaN**：`N > T` 的票（累计换手没到 100%）全 NaN → `N_mean` 无定义。与 §3.3 的 `N > T/7` 是同一现象的两种严重程度。
- ⚠️ **`ewm` 遇 NaN 的行为未实测**：安全写法是先切掉无效段再 `ewm(span=20, adjust=False)`，回填对齐。
- 原规格 `assert VOL.max() < 1e8` **防重复转、防不住少转**。改断言：`0 < turnover.quantile(0.99) < 0.3`。

## 9. 实施评估（2026-10-15）

### 9.1 公式组织形式：`dual` 参数 vs 新文件 → **抽共享内核 + 两个薄公式**

**先看两条硬约束**（决定了"复用"的战场不在 base.py）：

1. **`bool` 不在 `ParamSpec` 白名单**（`registry.py:123` 只允许 `int` / `float` / `choice`）
   → `dual` 只能用 `type="int"`（0/1），语义别扭，且要在 `tri_decay` 的参数面板里多一个数字框。
2. **返回值契约不可绕过**（`registry.py:141` → `_as_matrix` 严格 `(days, bins)` 二维非负）
   → `dual=1` 要返回 3 个矩阵必抛。**但冒烟用默认参数**（`dual=0` 走单分布）→ 仍能通过校验。
   **代价：`base.py:245` 必须加 dual 分支，两种做法都一样，省不掉。**

| 维度 | A. `tri_decay` 加 `dual` 参数 | B. 新文件 `tri_decay_dual.py` |
|---|---|---|
| `base.py` 加 dual 分支 | 必须 | 必须（**无差别**） |
| 一字板 / 越界 / 均价钳制 | 同文件，不重复 | **必须整段复制** → 两处漂移风险 |
| `tri_decay` 现有数值 | 有回归风险（改同一文件） | **零风险**（不碰它） |
| 参数空间 | `decay` × `dual`，再加 `period` → **三维且 `decay`/`period` 互斥**，registry 无条件校验能力 | 各自独立，干净 |
| 缓存 `lru_cache(24)` | `dual` 进 key → 条目翻倍，更快挤爆 24 | 独立 id，不冲突 |
| 文件复杂度 | 一文件两套逻辑，越改越乱 | 薄，但核心代码重复 |

**决策：方案 C —— 把递推内核抽到 `core/decay.py`，两个公式文件都调它。**

```
core/decay.py                  ← 新增 ~40 行，唯一一份递推 + 三角摊布 + 边界处理
  ├─ tri_decay.py              ← 改成调内核，现有行为逐值不变（单测保拍）
  └─ tri_decay_dual.py         ← 薄：一次循环维护两个向量 + 残差
```

收益：边界处理（**最易错的部分**）只有一份 ✅；`tri_decay` 不碰算法只换调用方式 → 零回归 ✅；
参数空间不爆炸（下拉两个条目，各管一条衰减律）✅；未来 EMA 路线再加两个文件，四种组合互不干扰 ✅。

> 代价只是多一个 40 行的 `core/decay.py`。相比"一字板处理复制两遍"，这个代价明显划算。

### 9.2 实现要点：`D_fix` 不需要单独递推

`D_fix = D_all − D_hot`，而两者**衰减因子完全相同**、只差注入条件 → 只需 **2 个向量**（不是 3 个）：

```
同一个循环、同一组衰减因子 f：
    chips_all *= f ;  chips_hot *= f
    chips_all += tri_t
    if VOL[t] >= B[t]:  chips_hot += tri_t
    # D_fix 不递推，直接取残差
out_fix = chips_all - chips_hot        # ≡「只注入 VOL<B 的日子」的递推，构造上恒 ≥ 0
```

- 开销只有单分布的 ~1.5 倍向量运算（不是 2 倍）。
- `D_fix ≥ 0` 由**构造**保证，不靠事后裁剪；浮点误差可能出 `-1e-18` → 加 `np.maximum(x, 0.0)` 保险即可。
- ⚠️ 注意：注入量是 `k`（份额）不是 `VOL[t]`（§3.1 已定），所以 `D_all` / `D_hot` 的注入必须都是 `k_t·tri_t`，
  **只有 mask 不同** —— 这正是"同衰减器"的前提。

| **P0-1 权重量级错误** | 原 `weight = α^age` 半衰期仅 0.1~0.3 天；改为 `α=2/(period+1)`、`λ=1−α`、`weight = α·λ^age`（标准 EMA 精确展开） |
