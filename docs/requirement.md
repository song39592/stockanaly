# 需求文档

## 项目定位

个人本地原型：股票池智能分析平台。Excel 导入每日股票池，做变动/连续在榜分析，个股 AI 调研，以及「红色小牛」多角色问答 Agent。仅本地运行，不公网部署。

## 模块需求

### 1. frontend（前端页面）

- Excel（.xlsx/.xls/GBK 文本）导入每日股票池，预览后按日期保存（localStorage）。
- 概览卡片：股票池总数、新增入池、出池、覆盖历史天数。
- 日期选择器：切换任意数据日，概览/变动/表格/图表联动。
- 变动分析：新增入池 / 出池 / 持续在池。
- 连续在榜天数：从选中日期往前数，中断重算；≥7 红、3–6 橙、1–2 灰。
- 表格排序 + 按细分行业分组；连续在榜排行榜 TOP20。
- ECharts 图表：行业分布饼图、规模趋势折线、入池/出池柱状。
- 数据管理：导出备份 / 恢复 / 按天删除 / 清空。
- 个股详情：进出池时间轴。
- 个股 AI 调研弹窗：调用 FastAPI `/api/stock/research`。
- 红色小牛问答助手：右下角悬浮按钮 → 聊天窗 + Skill 管理，对接 dsh 服务。
- 策略评分：只使用选中数据日及以前的信息计算市场状态、行业热度、连续性评分和候选清单。
- 历史复盘：使用未来已导入数据日价格评估 1/3/5/10 日结果，展示有效与缺失样本，不进行填补。
- 分析快照随数据备份导出，保留引擎版本、数据截止日和生成时间。
- 盘面及板块分析页（`market-sector.html`）：从股票池页顶部进入，展示 ① 外围环境 ② 大盘资金 ③ 板块β ④ 连板梯队 ⑤ 大面股；顶部提供交易日选择，选中日期后 ④⑤ 按该交易日查询（未选择时自动回溯最近交易日），①②③ 为实时行情不随日期变化；单项数据源失败时按模块降级提示，不影响其他模块。

### 2. backend_fastapi（FastAPI 调研后端）

- `GET /health`：健康检查。
- `POST /api/stock/research`：输入 `{code, name}`，采集巨潮公告 + 机构调研纪要 + 东财新闻，拼 prompt 调 LLM，返回 markdown 调研报告（含 12h 内存缓存）。
- 调研响应同时返回证据清单、来源链接、发布时间、采集时间、覆盖状态和确定性事件标签。
- 密钥存 `.env`，不硬编码。
- `GET /api/market/*`：盘面及板块五类数据（外围环境 / 大盘资金 / 板块β / 连板梯队 / 大面股），多源公开接口 + 单源失败降级 + 进程内缓存，支持 `?force=1` 强制刷新。

### 3. agent_dsh（红色小牛 Agent，基于 deepseek-harness）

- 自定义 Tool：
  - `getStockPoolSnapshot`：读当前会话的股票池快照（前端上传）。
  - `fetchStockResearch`：回连 FastAPI 调研接口。
- Skill 角色规则库：多套 `.skill` 规则文件，导入/导出，会话级绑定，注入 systemPrompt。
- Skill v2：支持策略类型、结构化参数、风险规则与自然语言解释规则；ID 唯一且导入前整体校验。
- 对外 REST：`/api/bull/*`（会话/快照/对话/绑定/技能 CRUD）。
- dsh webui 提供完整 Agent 轨迹调试（traceId 回看）。

## 非目标 / 约束

- 仅本地原型，禁止公网暴露服务。
- 快照存进程内存，重启丢失（可接受）。
- 不开启 shell / 文件执行能力，自定义工具只做 HTTP 与内存读取。
- 数据源为公开接口，反爬/改版可能导致个别来源失败，需优雅降级。
- 当前复盘仅基于用户导入价格，不处理复权、手续费、滑点、停牌和已出池后的缺失价格，页面必须显式披露该限制。
