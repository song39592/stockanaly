# 需求文档（功能范围现状）

> 本文描述**当前已实现**的功能范围。改功能时同步本文（见 `.codebuddy/rules/docs-sync.md`）。
> 目录与权威位置见 `.codebuddy/rules/project-structure.md`；接口细节见 `backend_fastapi/README.md`。

## 一、项目定位

个人本地原型：股票池智能分析平台。Excel 导入每日股票池 → 变动 / 连续在榜分析 →
个股 AI 调研 → 「红色小牛」多角色问答 Agent；并在此之上提供技术指标、策略回测、
筹码体系、历史行情下载等分析能力。

**仅本地运行，不公网部署。** 所有 LLM 调用走 DeepSeek 或任意 OpenAI 兼容平台，密钥只放本机 `.env`。

## 二、原生启动器（launcher / `stockpool.exe`）

主界面兼进程管家：内嵌拉起后端（:8000）与 dsh Agent（:3080），自带状态灯、托盘常驻、
运行日志、设置页，退出时收尾子进程。

一级标签页：

| 标签页 | 能力 |
|---|---|
| 盘面及板块 | 外围环境 / 大盘资金 / 板块β / 连板·大面股 / AI 分析（5 个二级页） |
| 个股分析 | K线 / 基本信息 / 记录·消息 / 估值 / 扫雷 / AI 分析 / 指标索引（7 个二级页） |
| 估值计算 | 输入代码 → 抓股价与财务 → 三情景每股价值，逐步展示计算过程 |
| 历史数据下载 | 按代码批量拉历史日 K，暂停 / 继续 / 取消 / 重试失败项，后台自动更新与闲时下载 |

| RPS 池 | RPS 横截面选股池与刷新 |
| 策略回测 | 策略选择与编辑 / 回测范围 / 回测结果 / 近期成果 / 单日策略 / 历史结果（6 个二级页） |
| 大佬策略实验室 | 资料 / 每日观点 / Skill / 审核（4 个二级页） |

| 服务控制台 / 运行日志 / 设置 | 启停服务、看日志、改数据目录与配色 |

## 三、后端（backend_fastapi，FastAPI，:8000）

11 组路由前缀：

| 前缀 | 职责 |
|---|---|
| `/api/indicators` | 技术指标清单 / 单算 / 批量算 / 诊断 |
| `/api/strategies` | 策略清单 / 校验 / 推荐 / 回测（异步进度 + 报告 + 逐笔成交明细） |
| `/api/history` | 股票池快照、K 线与消息面、RPS 池 |
| `/api/history/download` | 历史数据下载任务、队列、后台开关、通达信目录 |
| `/api/chip/scr` | SCR 选股（导入多期文件 → 周级三档分类） |
| `/api/chip/rank` | SCR90 周级排名 |
| `/api/chip/dist` | 筹码分布（价格分箱直方图 + 流通股本） |
| `/api/market` | 盘面五类数据 + AI 分析（含流式） |
| `/api/mentor` | 大佬策略实验室（资料 / 观点 / Skill / 评估的完整闭环） |
| `/api/stock` | 个股调研 / 估值 / 报价 / 搜索 / 档案 / 板块 / 扫雷 |
| `/api/system` | 数据目录、完整性校验、密钥密封、诊断包、行情重建 |

关键能力：

- **行情存储**：日 K 按年分片存**不复权原始价** + 后复权因子，复权价一律现算；
  数据目录在仓库外（默认 `<程序上一级>/stockanaly-data`）。
- **数据可信**：每个库有 `_meta` 签名，日 K 另有按股指纹；发现被改动 → 拒绝返回 →
  自动全量重抓替换。**丢数据可重拉，错误数据不可接受。**
- **技术指标**：插件化（一个指标一个文件，自动注册），输出与 K 线同序的标准化序列，
  按 `panel`（主图 / 副图 / 分布）路由到前端，新增指标不必改前端。
- **策略回测**：策略输出**目标权重向量**，买卖由引擎 diff 派生；含整手 / 涨跌停 / 停牌约束、
  成本分层、胜率口径拆分与交易明细；回测结果页的成交明细**一行 = 一次买卖**
  （与指标卡「交易次数」同口径），逐笔明细随结果一起下发（上限与标注口径见
  `backend_fastapi/strategies/ARCHITECTURE.md`「逐笔明细的下发口径」）。
- **降级**：任一数据源失败只写 `errors` 字段，其余模块照常返回。

## 四、前端（frontend，原生 HTML/JS）

| 页面 | 能力 |
|---|---|
| `home/index.html` | 股票池追踪主页面：概览卡片 / 策略评分与历史复盘 / 变动分析 / 股票池表 / 连续在榜 TOP20 / ECharts 三图 / 数据管理 / 个股 AI 调研弹窗 / 红色小牛聊天窗 / Skill 管理 |
| `chip-scr/index.html` | SCR 选股：导入多期「临时条件股」文件 → 周级三档分类（磨主峰 / 向下破位离榜 / 启动型离榜），阈值可调 |
| `mentor-lab/index.html` | 大佬策略实验室：资料 → 观点 → Skill 版本 → 人工晋级 → 回测评估 |

- 数据存浏览器 `localStorage`（`stockPool.data.v1` / `stockPool.analysis.v1`），
  可导出备份 / 恢复 / 按天删除 / 清空。
- 评分与回测由共享引擎 `frontend/shared/analysis-engine.js` 计算，**不使用目标日之后的数据**。

## 五、AI Agent（agent_dsh / dsh，:3080）

- 自定义 Tool：`getStockPoolSnapshot`（读前端每轮上传的快照）、
  `fetchStockResearch`（回连 :8000 调个股调研）。
- Skill 角色规则库（`skills_library/*.skill`，纯 JSON）：会话级绑定，注入 systemPrompt。
  内置 `general` 通用分析 / `short-trader-01` 短线猎手 / `bft` 巴菲特价值投资。
- REST 网关 `/api/bull/*`：会话、快照、对话、Skill CRUD、导入导出。
- dsh webui 与网关同端口，可回看完整 Agent 轨迹（traceId）。

## 六、非目标 / 约束

- 仅本地原型，禁止公网暴露服务；dsh 为预览版，接口可能变动。
- 快照与会话→Skill 绑定存 dsh 进程内存，**重启丢失**（`.skill` 文件本身落盘持久化）。
- 不开启 shell / 文件执行能力；自定义工具只做 HTTP 与内存读取。
- 数据源均为公开接口，反爬 / 改版可能导致个别来源失败，已做优雅降级。
- 前端复盘仅基于用户导入价格，不处理复权、手续费、滑点、停牌与出池后缺失价格，页面显式披露。
- 回测**固定日线**：年化与夏普按 252 交易日折算，不开放周 / 月周期。
