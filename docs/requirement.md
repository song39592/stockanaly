# 需求文档（功能范围现状）

> 本文描述**当前已实现**的功能范围。改功能时同步本文（见 `.codebuddy/rules/docs-sync.md`）。
> 目录与权威位置见 `.codebuddy/rules/project-structure.md`；接口细节见 `backend_fastapi/README.md`。

## 一、项目定位

个人本地原型：股票池智能分析平台。Excel 导入每日股票池 → 变动 / 连续在榜分析 →
个股 AI 调研 → 「红色小牛」多角色问答 Agent；并在此之上提供技术指标、策略回测、
筹码体系、历史行情下载等分析能力。

**仅本地运行，不公网部署。** 所有 LLM 调用走 DeepSeek 或任意 OpenAI 兼容平台，密钥只放本机 `.env`。

## 三、后端（backend_fastapi，FastAPI，:8000）

11 组路由前缀：

| 前缀 | 职责 |
|---|---|
| `/api/indicators` | 技术指标清单 / 单算 / 批量算 / 诊断 |
| `/api/strategies` | 策略清单 / 校验 / 推荐 / 回测（异步进度 + 报告 + 逐笔成交明细） |
| `/api/history` | 股票池快照、K 线与消息面、RPS 池 |
| `/api/history/download` | 历史数据下载任务、队列、后台开关、通达信目录 |
| `/api/chip/scr` | SCR 选股（导入多期文件 → 周级三档分类） |
| `/api/chip/rank` | SCR90 周级排名 |
| `/api/chip/dist` | 筹码分布（价格分箱直方图 + 流通股本） |
| `/api/market` | 盘面五类数据 + AI 分析（含流式） |
| `/api/mentor` | 大佬策略实验室（资料 / 观点 / Skill / 评估的完整闭环） |
| `/api/stock` | 个股调研 / 估值 / 报价 / 搜索 / 档案 / 板块 / 扫雷 |
| `/api/system` | 数据目录、完整性校验、密钥密封、诊断包、行情重建 |

关键能力：

- **行情存储**：日 K 按年分片存**不复权原始价** + 后复权因子，复权价一律现算；
  数据目录在仓库外（默认 `<程序上一级>/stockanaly-data`）。
- **指数行情**：指数**不是股票** —— 独立表 `index_bars`（独立库 `bars/indices.db`），
  代码带市场前缀（`sh000001` / `sz399001`），无复权概念；
  前端在个股分析页按指数代码进指数模式看 K 线（指标、周期、范围照常）。
- **数据可信**：每个库有 `_meta` 签名，日 K 另有按股指纹；发现被改动 → 拒绝返回 →
  自动全量重抓替换。**丢数据可重拉，错误数据不可接受。**
- **技术指标**：插件化（一个指标一个文件，自动注册），输出与 K 线同序的标准化序列，
  按 `panel`（主图 / 副图 / 分布）路由到前端，新增指标不必改前端。
  主图叠加有两种图元：`line`（折线，如均线 / 成本线）与 `hline`（水平阶梯线，
  用于**价位参考线**）。筹码类的 `HTOP`（**筹码密集上沿**）属后者 —— 当日筹码分布
  沿价格轴看往往不止一座山，本指标取**位置最靠上**（价格最高）的那座山的**峰顶价位**
  （判据只看位置、不看筹码高度），即「筹码密集区的上沿」，画成主图上的水平线，
  可直接与 K 线比对；它与 `COST` 的**峰位价**（最胖那座山的峰顶）是两个不同的点。
- **策略回测**：策略输出**目标权重向量**，买卖由引擎 diff 派生；含整手 / 涨跌停 / 停牌约束、
  成本分层、胜率口径拆分与交易明细；回测结果页的成交明细**一行 = 一次买卖**
  （与指标卡「交易次数」同口径），逐笔明细随结果一起下发（上限与标注口径见
  `backend_fastapi/strategies/ARCHITECTURE.md`「逐笔明细的下发口径」）。
  唯一例外：**买不进的建仓也逐条列在同一张表里**（隔日一字涨停 → 没成交 → 收益 0、
  备注「买不进」）；**清仓延后的那一笔**（隔日一字跌停 → 顺延到开板日卖出）在备注列
  写明延后天数与计划清仓日 —— 不单开明细表，避免几百行失败挤掉真正的结果。
  内置策略（策略名即 id，插件化自动注册）：`jwzz_cross`（JWZZ 上穿/下穿，每日重选前 N）、
  `jwzz_cross_safe`（JWZZ 上穿/下穿 **+ 跳过炸板买入**：买入日当天涨停开盘、盘中炸板
  的票视为隔夜单未成交 → 这一笔不买；一字板不算炸板，那是买不进）、
  `jwzz_cross_timing`（JWZZ 上穿/下穿 **+ 大盘状态择时**：选股口径同 `jwzz_cross`，
  只多一层「大盘在 MA 之上按正常仓位/持仓上限持有、跌破则降仓或空仓」的开关；
  状态判定**无前视**（决策日只用前一日收盘及更早），空仓 = 真清仓 → 付换手成本）、
  `jwzz_cross_all`（JWZZ 上穿/下穿，全量等权）、`jwzz_hold`（JWZZ 买入后持有到下穿，
  槽位制：最多 N 只、单票固定仓位、每日按 JWZZ 排名买前 k 只、槽位满则当天买不进）、
  `jwzz_htop`（JWZZ 强势区买入 / 下穿或破 HTOP 清仓：买入按 JWZZ 排名取前 N、
  每只固定 `M`（默认 1/20），**跌出前 N 不卖**；只在 JWZZ 收盘下穿 95‰
  或当日最低价下破 HTOP（筹码密集上沿）时清仓；HTOP 与回测同复权口径、
  按收盘价成交——实盘可用条件单在 HTOP 价位挂单）、
  `kl_pool_jwzz`（KL 入池 + JWZZ 买卖）、`scr90`、`macd`、`rps_score` 等；
  策略口径与参数见 `backend_fastapi/strategies/ARCHITECTURE.md`。
  **大盘状态用的指数序列**已落盘到**独立库** `bars/indices.db`（表 `index_bars`，
  code 带市场前缀，如 `sh000001`）：指数**不是股票**，不进回测池、不与个股撞主键；
  拉取 `python scripts/download_indices.py`（上证 / 深证成指 / 沪深300 / 中证1000 / 中证全指）。
  **回测的基准（指数）对比**：基准选择在「**回测结果**」页（不在「回测范围」页）——
  基准是结果的对照物、不是回测的输入条件；它只影响 alpha / beta / IR 的计算，
  **净值图上那条金线恒为「等权全池买入持有」**，与选哪个指数无关（两个口径别混）。
  `benchmark` 参数填**指数代码**，形态是「市场前缀 + 6 位数字」（`sh000300`）——
  前端从指数清单里选、不让手输；不带前缀的会被当**个股**去取（`000300` 是只个股），
  alpha/beta 会算成个股的、而界面上不会有任何提示。
  路由在数据层一处（`data.load_benchmark`）；指数本地没行情时后端取不到 →
  alpha/beta/IR 置空并给出提示，前端不显示空卡片。
  **回测范围页的「排除特征」**：勾了「剔除 ST / \*ST」时，ST 名称名单要联网取
  （数据源无历史名单 → 按**当前**名单判定，含前视偏差，报告会显式声明）。
  名单**取不到 / 覆盖不足 95%** → **中止**并给出可操作提示（取消该勾选，或恢复网络后重试）；
  不会静默降级成「一只没剔」—— 那种情况下报告看起来像「本来就没有 ST」，
  两份报告的池子可能差上百只却看不出差别。
  报告另带 `pool_signature`（池子结果指纹：基准日 + 区间 + 每项剔除只数 + 池大小），
  两份报告一比即知池子是否真的相同。
  **单股仓位上限**（回测范围页设置，占比 % 或金额元，两者取更严者）：留空 = 不限
  = 完全按策略给的仓位执行；设了之后策略给出的目标权重被逐票压到上限以下（只压低、
  绝不抬高），空出来的仓位是现金 → 直接反映在资金利用率上，且截断规模会写进结果
  指标与告警（不静默改数据）；单日策略的买入金额用同一口径，避免界面金额与回测仓位对不上。
  **涨停开盘应对**（回测范围页设置，**全局生效**、只作用于回测）：隔夜单在次日
  **涨停开盘**时三选一 —— ①**不撤单**（照常买入，现状）②**撤单**（涨停开盘当日不买；
  该份额度当日是现金、**不重分配**给其他票）③**涨停条件单**（炸板票只有收盘仍封住
  涨停价才进，否则撤单）。撤单是**策略主动放弃**，与「一字涨停买不进」（物理约束）
  **分开归因**：结果里单独给一组统计（撤单笔数、涉及的目标权重合计），逐条明细并进
  成交明细表（备注「涨停开盘撤单」）。要衡量「这个条件值多少钱」用**两个不同回测范围**
  各自跑一遍对照（引擎不做影子账本）。口径见
  `backend_fastapi/core/limit_price.py` 与 `strategies/ARCHITECTURE.md`。
  **买入时滤除异动**（回测范围页设置，默认全关）：可勾选 price（已触发价格异动）、
  turnover（换手率异动）、severe（严重异动）、near_price（将触发价格异动）、
  near_severe（将触发严重异动）。只在**买入建仓时**判定，用 lag=1 防前视；
  将触发两档分别按预测页的价格 80% 预警（20/30%，ST 12%）与 10/30 日严重阈值 85%
  判定。无法判定（valid=false）默认放行并计数，绝不静默当成「无异动」。
  被拦下的建仓不成交，逐条并进成交明细表（备注「买入时异动放弃」），
  与「一字板买不进」「涨停开盘撤单」分开归因；结果里单独给一组统计
  （生效类型、拦截笔数、涉及目标权重、无法判定放行次数、生效日期）。
- **降级**：**展示类**数据源失败只写 `errors` 字段，其余模块照常返回；
  但**参与口径判定**的数据源（ST 名称名单等）取不到 / 覆盖不足 → **中止并提示**
  （回测范围页直接报 400 + 提示「取消勾选『剔除 ST/*ST』后重跑，或恢复网络」），
  **不静默降级** —— 降级后报告的「剔除明细」看起来像「本来就没有 ST」，
  口径指纹也算不出差别（实测两份报告指纹相同、池子差 126 只、收益差 5%）。

## 五、AI Agent（agent_dsh / dsh，:3080）

- 自定义 Tool：`getStockPoolSnapshot`（读前端每轮上传的快照）、
  `fetchStockResearch`（回连 :8000 调个股调研）。
- Skill 角色规则库（`skills_library/*.skill`，纯 JSON）：会话级绑定，注入 systemPrompt。
  内置 `general` 通用分析 / `short-trader-01` 短线猎手 / `bft` 巴菲特价值投资。
- REST 网关 `/api/bull/*`：会话、快照、对话、Skill CRUD、导入导出。
- dsh webui 与网关同端口，可回看完整 Agent 轨迹（traceId）。

## 六、非目标 / 约束

- 仅本地原型，禁止公网暴露服务；dsh 为预览版，接口可能变动。
- 快照与会话→Skill 绑定存 dsh 进程内存，**重启丢失**（`.skill` 文件本身落盘持久化）。
- 不开启 shell / 文件执行能力；自定义工具只做 HTTP 与内存读取。
- 数据源均为公开接口，反爬 / 改版可能导致个别来源失败，已做优雅降级。
- 前端复盘仅基于用户导入价格，不处理复权、手续费、滑点、停牌与出池后缺失价格，页面显式披露。
- 回测**固定日线**：年化与夏普按 252 交易日折算，不开放周 / 月周期。
