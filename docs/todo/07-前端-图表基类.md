## 问题
5 个自绘表面各自重复了「初始化 + 尺寸 + 抗锯齿」等样板，且**抗锯齿有的开了有的没开**，观感不一致；
`ChipPanel` 还**每帧 new 3 个 StringFormat**。

## 建议做法
抽 `ChartControl : Control` 基类，只收 **#1 + #2 + #3 + #4**：
- 构造里统一 `SetStyle(...)`、`SmoothingMode` 在 `OnPaint` 基类里设好
- 提供 `protected static readonly StringFormat FmtLeft/FmtRight/FmtCenter`
- 重写 `GetPreferredSize`

**#5/#6/#7 建议不动**（网格色随第 01 项一起解决；映射公式只有一行，抽出反而难读）。

## 注意（踩坑点）
1. **`StEquityPaint` 进不了基类** —— 它是 `PictureBox` 的事件处理器，不是 Control 子类，要留例外（最多手工抄 `SmoothingMode`）。
2. `FmtLeft/FmtRight/FmtCenter` 现在是 `static readonly` 缓存，**写法是正确的**：`StringFormat` 不可变但非线程安全，做静态缓存没问题 —— **别改成每帧 new**。
3. **`ChipPanel` 与 `KLineChart` 有真实耦合**：`TryGetPriceAxis`（StockPage.cs:2893）+ `PriceAxisChanged` 事件（:2890）。
   抽基类时不要打断这段协作 —— ChipPanel 依赖 K 线发布的价格轴来对齐。
4. 统一网格色要同时改 `BuildPalette()`（StockPoolLauncher.cs:912），那里现在只维护四个底色，语义色不参与换肤（见第 01 项）。
