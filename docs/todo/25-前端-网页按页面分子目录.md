# 25 · 前端：网页按页面分子目录

## 问题
`frontend/` 现在是**平铺**的 7 个文件，页面与共享资源混在一起。

## 现状
`frontend/` 内容：
| 文件 | 归属 |
|---|---|
| `chip-scr.html` | 筹码体系 · SCR 选股页面 |
| `index.html` | 首页/入口 |
| `mentor-lab.html` | 大佬策略实验室页面 |
| `analysis-engine.js` | 分析引擎（被哪些页面引用需确认） |
| `analysis-engine.test.cjs` | 上述引擎的测试 |
| `theme.js` | **共享**：主题 |
| `theme-state.js` | 共享：主题状态（已被 `.gitignore` 忽略，由启动器写入） |

### 硬耦合（决定改动范围）
- 启动器打开网页：`OpenWebPage(fileName, title)`（StockPoolLauncher.cs:872-876）内部是
  `Path.Combine(_root, "frontend", fileName)` —— **HTML 移进子目录后这里必须改**。
- 已知调用点：`BuildChipPage` 里的 `OpenWebPage("chip-scr.html", "SCR 选股 · 筹码体系")`（:1213 附近）；
  另有 `mentor-lab` / `index` 的入口（需执行时再确认具体行号）。
- `theme-state.js` 由启动器写入 `frontend/`（`.gitignore:61` 已忽略）—— 位置要跟着共享目录走。

## 建议做法
```
frontend/
├─ chip-scr/       index.html  （原 chip-scr.html）
├─ mentor-lab/     index.html  （原 mentor-lab.html）
├─ home/           index.html  （原 index.html）
└─ shared/
    ├─ theme.js
    ├─ theme-state.js
    └─ analysis-engine.js (+ test)
```
同步改启动器 `OpenWebPage`：入参从「文件名」改成「子目录名」（`Path.Combine(_root,"frontend",page,"index.html")`）。

## 注意（踩坑点）
1. **HTML 内部的相对引用会变**：页面里 `<script src="theme.js">` 之类要改成 `../shared/theme.js`。
   执行时必须逐个 HTML 检查 `src=` / `href=` / `fetch(` 里的路径。
2. `analysis-engine.js` 若被多个页面引用，必须放 `shared/`；若只被一个页面用，放该页面目录即可 ——
   **执行时先确认引用关系再决定**，不要盲目归到 shared。
3. 改动需要**重新编译 exe**（启动器路径变了）。
4. `theme-state.js` 是运行期生成文件，`.gitignore` 规则 `frontend/theme-state.js` 要同步改成新路径。
