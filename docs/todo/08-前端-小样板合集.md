## 8.1 `IsOk(j)` —— 6 处同构
「响应是否 ok」判定样板：
`(j != null && j.TryGetValue("ok", out okv) && okv is bool && (bool)okv)`
- StockPage.cs:682, 1487；ValuationPage.cs:362, 389；MarketPage.cs:937
- 变体：ChipRankPage.cs:225（`j.ContainsKey("ok") && j["ok"] is bool && (bool)j["ok"]`）
→ 抽 `static bool IsOk(Dictionary<string,object> j)`。风险极低。

## 8.2 `ErrOf(j, fallback)` —— 至少 4 份
「error → detail → 兜底文案」三段式：
- ValuationPage.cs:399-404：`error` → `detail` → raw 前 300 字 → `"计算失败"`
- StockPage.cs:1490-1492：`detail` → `error` → `"加载失败"` ⚠️ **顺序与上面相反**
- MarketPage.cs:940-942：`error` → `detail` → `"分析失败"`
- StrategyPage.cs:785 `StErrMsg`：取 `error.message`
→ **注意：别统一 detail/error 的优先级顺序**，两处相反可能是有意的。

## 8.4 `ToggleVisible(Control, Button, showText, hideText)` —— 2 处
- `MktToggleFold(DataGridView, Button)` MarketPage.cs:1083（调用 3 次：:329,356,376）
- `ValuationToggleParams()` ValuationPage.cs:248（`_vParams` + 文案「展开参数/收起参数」）
→ 同一模式，只是控件类型不同。收益低（各 3 行），顺手做。
⚠️ 另两种折叠不是同一模式，不要混进来：

## 8.5 `Debounce(ref Timer, ms, Action)` —— 2 份逐字同构
- `ScheduleChipReload()` StockPage.cs:1223（400ms）
- `ScheduleBoardsRetry()` StockPage.cs:957（6000ms，多一个重试计数）
体是逐字同构：`if(t==null){ t=new Timer(); t.Interval=X; t.Tick+=delegate{ t.Stop(); ...; } } t.Stop(); t.Start();`
→ 抽 `Debounce`。
⚠️ 另 3 个轮询定时器**不算重复**（用途不同）：ChipRankPage.cs:110(2000ms)、DownloadPage.cs:499(1500ms)、StockPoolLauncher.cs:620(3000ms)。

## 8.6 `FlatBtn(...)` —— 4 处手写 8 行
扁平小按钮配置（`FlatStyle=Flat` + `BorderSize=0` + `Font=YaHei UI 9f` + `TabStop=false` + `Margin=(0,0,2,0)`）被抄了 4 遍：
- StockPage.cs:586-597（subtab 按钮）
- MarketPage.cs:136-147（**与上一份逐字相同**）
- StrategyPage.cs:148-156（同，缺 Width/Height/AutoSize 三行）
- StockPage.cs:2360-2368（折叠箭头按钮，另加 26×26）
→ 抽 `FlatBtn(text, click, w, h)`。
注：若先做第 05 项（SubTab 抽取），前 3 处会被一并吃掉。
