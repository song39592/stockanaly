使用说明

纯本地工具，数据只保存在你的浏览器 localStorage 中，不上传任何服务器。

1. 导入数据：点击「导入今日股票池」，选择 .xlsx / .xls 文件（也支持通达信等软件导出的 GBK 文本表格）。解析后预览确认，即以当天日期保存。

2. 查看历史：顶部日期选择器切换到任意有数据的一天，概览卡片、变动分析、表格和图表都会联动。

3. 连续在榜天数：从选中日期往前数，只要连续出现就累加，中断则重新计算。≥7 天红色、3–6 天橙色、1–2 天灰色。

4. 表格排序：点击表头切换排序；点击「细分行业」按行业分组（组内按连续天数降序）。

5. 数据备份：「导出备份」下载 JSON 文件；「恢复数据」从 JSON 导入；「数据管理」可按天删除或清空。

6. 字段识别：自动识别表头中的「代码 / 名称 / 细分行业 / 地区」列；行业为空归为「未分类」；股票代码自动补零到 6 位、自动去重。

7. 个股研究详情：点击表格/排行榜中的股票，查看真实日 K、均线、成交量、进出池标记和公告/新闻时间轴；详情页中的“AI 调研”按钮可继续生成主营业务、近期事项和多空观点报告。行情与调研依赖本地 FastAPI 后端，每次双击项目根目录的 启动系统.bat 即可自动启动。
